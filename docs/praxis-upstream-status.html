Praxis gateway — upstreaming status and gaps

Ongoing work: what the dogfood gateway (feat/dogfood-gateway) runs today, which pieces are already in upstream review, and which still need a PR. Drawn as two lanes: the request lane runs left to right, the response lane runs back right to left — spend is only knowable after the provider answers, so every token action sits on the response lane. Filters cooperate through filter_metadata — in-memory, per-request, dropped when the response completes.
